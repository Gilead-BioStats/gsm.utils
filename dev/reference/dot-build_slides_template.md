# Build template content for a slide deck

Build template content for a slide deck

## Usage

``` r
.build_slides_template(strTitle, intIndex)
```

## Arguments

- strTitle:

  (`string`) Display title.

- intIndex:

  (`numeric`) Sort-order index. `NULL`, `NA`, and length-0 vectors are
  treated as absent.

## Value

Character vector of template lines.
